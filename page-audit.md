# Portfolio page audit

Use this checklist after you replace placeholders and before you share the site.

## Personal details

- [ ] `[YOUR FULL NAME]` is replaced in the page title, logo, hero heading, profile card, and footer.
- [ ] `[YOUR CITY, COUNTRY]` is replaced or removed.
- [ ] About Me text is rewritten in your own words.
- [ ] `[YOUR INTERESTS...]` is replaced with real interests.
- [ ] Education placeholders (`[YOUR COLLEGE OR UNIVERSITY NAME]`, `[YOUR SCHOOL NAME]`, `[BOARD NAME]`, years) are updated.
- [ ] Skills match what you can honestly talk about.

## All five projects

- [ ] Python Programs Collection (factorial, Fibonacci, structure-to-dictionary conversion) is present and accurate.
- [ ] Messy Python Code Improvement is present and accurate.
- [ ] Bug Fixing Using Cursor AI is present and accurate.
- [ ] Interactive Quiz Application is present and accurate.
- [ ] Book Reading List Application is present and accurate.
- [ ] Each card still has a title, short description, and technologies.

## Links

- [ ] No invented URLs remain on the live site.
- [ ] `[ADD YOUR REPOSITORY URL]` is replaced only with a real repository, or the link is removed until the repo exists.
- [ ] `[ADD YOUR LIVE APP URL]` is replaced only with a real live app, or the link is removed until it exists.
- [ ] Contact links use your real email, phone, LinkedIn, and GitHub, or stay clearly marked as placeholders.
- [ ] `mailto:` and `tel:` values match the visible contact text.

## Accessibility

- [ ] Skip to main content link is usable with the keyboard.
- [ ] Primary navigation can be reached with Tab and activated with Enter.
- [ ] Mobile menu button updates `aria-expanded` and can be closed with Escape.
- [ ] Theme toggle has a clear accessible name and `aria-pressed` state.
- [ ] Form fields (project search, chatbot message) have visible labels.
- [ ] Focus outlines remain visible in light and dark mode.
- [ ] Headings follow a sensible order: one `h1`, then `h2` section titles.

## Search

- [ ] Typing in the project search filters cards by title.
- [ ] Search also matches description text.
- [ ] Search also matches technology labels such as Python or JavaScript.
- [ ] Clearing the search shows all five cards again.
- [ ] A no-match query shows the empty-state message and a live status update.

## Theme toggle

- [ ] The control switches between light and dark palettes.
- [ ] Navy, white, and gold remain readable in both themes.
- [ ] The chosen theme is remembered after a page reload.
- [ ] The button label/icon matches the action (switch to dark or switch to light).

## Chatbot and secrets

- [ ] The chatbot section still states that it is a local demo, not a live API.
- [ ] No API keys, tokens, or secrets appear in HTML, CSS, JavaScript, README, or this audit file.
- [ ] Any future AI connection is planned through a backend, not browser-side keys.
